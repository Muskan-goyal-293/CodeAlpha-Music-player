# CodeAlpha-Music-player
## Overview

A responsive Music Player Web Application built using **HTML, CSS, and JavaScript**. The project provides a simple and interactive interface where users can browse songs, play music, switch between tracks, and view album artwork.

## Features

* 🎶 Play songs from a custom playlist
* ⏮ Previous song navigation
* ⏭ Next song navigation
* 🖼 Dynamic album cover updates
* 📝 Currently playing song display
* 📱 Responsive design for desktop, tablet, and mobile devices
* 🎨 Modern user interface with animations and hover effects
* 🔁 Loop support for audio playback
* 📝 Beautiful home animation 

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How It Works

1. The application loads a predefined playlist.
2. Users can select any song from the library.
3. The selected song starts playing instantly.
4. Album artwork and song title update automatically.
5. Previous and Next buttons allow easy navigation through the playlist.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Muskan-goyal-293/CodeAlpha-Music-player.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
